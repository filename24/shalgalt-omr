**shalgalt-omr** нь шалгалтын OMR (бөмбөлөг будах) хариултын хуудсыг **интернэт холболтгүйгээр**,
таны компьютер дээр автоматаар уншиж дүгнэдэг программ юм. Багш та дараах ажлуудыг хийж чадна:

<Cards>
  <Card href="/user/editor" title="Загвар зохиох">
    Хариултын хуудасны загварыг визуал засварлагчид зурна.
  </Card>
  <Card href="/user/editor" title="Хэвлэх PDF гаргах">
    Загвараа хэвлэхэд бэлэн PDF болгож хадгална.
  </Card>
  <Card href="/user/grading" title="Дүгнэх">
    Сканнердсан буюу гар утсаар авсан хуудаснуудыг автоматаар уншуулж оноо тавина.
  </Card>
  <Card href="/user/review" title="Гараар шалгах">
    Итгэл багатай (эргэлзээтэй) хуудсуудыг гар аргаар нягтлан засна.
  </Card>
  <Card href="/user/export" title="Excel рүү гаргах">
    Дүнг хүснэгт болгон гаргах, эсвэл бүх төслийг `.shalgalt` файлаар хуваалцана.
  </Card>
</Cards>
