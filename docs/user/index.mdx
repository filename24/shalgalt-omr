# shalgalt-omr — Хэрэглэгчийн гарын авлага

**shalgalt-omr** нь шалгалтын OMR (бөмбөлөг будах) хариултын хуудсыг **интернэт холболтгүйгээр**,
таны компьютер дээр автоматаар уншиж дүгнэдэг программ юм. Багш та дараах ажлуудыг хийж чадна:

1. **Загвар зохиох** — хариултын хуудасны загварыг визуал засварлагчид зурна.
2. **Хэвлэх PDF гаргах** — загвараа хэвлэхэд бэлэн PDF болгож хадгална.
3. **Дүгнэх** — сканнердсан буюу гар утсаар авсан хуудаснуудыг автоматаар уншуулж оноо тавина.
4. **Гараар шалгах** — итгэл багатай (эргэлзээтэй) хуудсуудыг гар аргаар нягтлан засна.
5. **Excel рүү гаргах** — дүнг хүснэгт болгон гаргах, эсвэл бүх төслийг `.shalgalt` файлаар хуваалцана.

## Нууцлал

Энэ программ нь **интернэт шаарддаггүй**, **ямар ч мэдээлэл гадагш илгээдэггүй**. Сурагчдын
мэдээлэл зөвхөн таны компьютер дээр хадгалагдана. Дэлгэрэнгүйг
[Нууцлалын мэдэгдэл](/user/privacy) хэсгээс үзнэ үү.
