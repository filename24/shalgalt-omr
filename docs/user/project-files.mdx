# Төслийн файл (`.shalgalt`)

`.shalgalt` файл нь **бүхэл шалгалтын төсөл**-ийг (загвар + хариултын түлхүүр + дүгнэсэн
хуудаснууд + сурагчдын жагсаалт) нэг файлд багтаасан хэлбэр юм. Үүгээр та өөр компьютер
руу зөөх, эсвэл хамтран ажиллагсадтайгаа хуваалцаж болно.

## Онцлог

- Нэг файл, ердийн zip хэлбэртэй тул шифрлээгүй үед ямар ч zip програмаар нээж үзэж болно.
- **Нэмэлтээр нууцлах боломжтой** — нууц үг (passphrase) тавьж бүх агуулгыг шифрлэнэ.
- Гарчиг, огноо, хуудасны тоо зэргийг агуулсан **manifest хэсэг нь үргэлж задгай** байдаг тул
  нууц үг оруулахаас өмнө төслийн ерөнхий мэдээллийг урьдчилан харж болно. Энэ хэсэгт
  сурагчдын хувийн мэдээлэл **байхгүй**.

## Нээх ба хадгалах

- **Нээх** — `.shalgalt` файл дээр давхар товшиход програм нээгдэж, шифрлэсэн бол нууц үг
  асууна. Агуулга нь таны локал санд сэргээгдэнэ.
- **Хадгалах / Гаргах** — төслөө `.shalgalt` болгон гаргахдаа нууц үг тавих эсэхээ сонгоно.

> 📷 *Дэлгэцийн зураг: Төсөл нээх — нууц үг асуух цонх.*
