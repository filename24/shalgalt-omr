---
title: Хурдан эхлэх
description: Суулгахаас эхлээд эхний шалгалтыг дүгнэх хүртэлх алхмууд.
---

Энэ хэсэг танд **суулгах → эхний загвар → эхний дүгнэлт** хүртэлх замыг богино хугацаанд
танилцуулна.

<Steps>

<Step>
### Суулгах

1. [Releases хуудаснаас](https://github.com/filename24/shalgalt-omr/releases) өөрийн
   үйлдлийн системд тохирох суулгацыг татаж аваад суулгана (Windows `.exe`/`.msi`,
   macOS `.dmg`, Linux `.AppImage`/`.deb`).
2. Программыг анх удаа нээхэд өгөгдлийн сан таны компьютерт автоматаар үүснэ. Ямар нэг
   тохиргоо хийх шаардлагагүй.

<Callout type="info" title="Дэлгэцийн зураг">
  Хяналтын самбар (нүүр хуудас). Жагсаалт: `docs/user/screenshots-needed.md`.
</Callout>
</Step>

<Step>
### Загвар зохиох

1. **Хяналтын самбар** дээрх **Шинэ загвар** товчийг дарж [Загвар засварлагч](/user/editor)
   руу орно.
2. Дэлгэц дээр булангийн **ArUco тэмдэг** 4-ийг байрлуулна (автоматаар бэлэн ирдэг).
3. **Бөмбөлгийн бүлэг** нэмж асуултуудаа (жишээ нь A–D сонголттой), мөн шаардлагатай бол
   **Сурагчийн дугаар**, **Хувилбар**-ын бүлгийг байрлуулна.
4. **Хадгалах** товчийг дарна.

<Callout type="info" title="Дэлгэцийн зураг">
  Загвар засварлагчийн хэрэгслийн мөр ба бөмбөлгийн бүлэг.
</Callout>
</Step>

<Step>
### Хэвлэх PDF гаргах

Засварлагчийн **PDF болгон гаргах** товчийг дарж хэвлэхэд бэлэн хуудсыг хадгална. Хэвлэхдээ
[Хэвлэх зөвлөмж](/user/printing)-ийг анхаарна уу (масштаб 100%, тод хар бэх).
</Step>

<Step>
### Шалгалт ба хариултын түлхүүр үүсгэх

1. **Шалгалт** цэс рүү орж **Шинэ шалгалт** үүсгэн, дээр хийсэн загвараа сонгоно.
2. Шалгалтын дотор **хариултын түлхүүр (хувилбар)** нэмнэ. Зөв хариултуудыг гараар сонгох,
   эсвэл бөглөсөн нэг хуудсыг сканнердан **уншуулж** оруулж болно.

<Callout type="info" title="Дэлгэцийн зураг">
  Шалгалтын дэлгэрэнгүй — хариултын түлхүүр засах.
</Callout>
</Step>

<Step>
### Хуудаснуудыг дүгнэх

1. **Дүгнэх** цэс рүү орно.
2. Сканнердсан **PDF файл(ууд)**-аа сонгоно.
3. Аль **шалгалт / хувилбар**-ыг дүгнэхээ сонгоно (олон хувилбарыг автоматаар таниулж болно).
4. **Эхлүүлэх** товчийг дарна. Явц нь дэвшилтийн мөрөөр харагдана — программ царцахгүй.

<Callout type="info" title="Дэлгэцийн зураг">
  Дүгнэх дэлгэц — файл сонголт ба дэвшилтийн мөр.
</Callout>
</Step>

<Step>
### Эргэлзээтэй хуудсыг шалгах

Дүгнэлт дуусахад **гараар шалгах** шаардлагатай хуудсууд тэмдэглэгдэнэ. [Гараар шалгах](/user/review)
дэлгэцэд бөмбөлгүүдийг нэг бүрчлэн нягталж засна.
</Step>

<Step>
### Дүн гаргах

**Дүн** цэснээс шалгалтын дүнг үзэж, **Excel рүү гаргах** товчоор хүснэгт болгон татаж авна.
Дэлгэрэнгүйг [Excel рүү гаргах](/user/export) хэсгээс үзнэ үү.
</Step>

</Steps>

<Callout type="info" title="Зөвлөмж">
  Бэлэн жишээ төслүүдийг ([Жишээ файлууд](/user/samples)) татаж аваад дээрх алхмуудыг туршиж
  үзэж болно.
</Callout>
