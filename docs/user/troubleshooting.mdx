# Алдаа засах ба түгээмэл асуулт (FAQ)

### Хуудсыг таниж чадахгүй / булангийн тэмдэг олдсонгүй

- 4 булангийн **ArUco тэмдэг** бүгд зурагт бүтэн орсон эсэхийг шалга.
- Хэвлэлт бүдэг бол [Хэвлэх зөвлөмж](/user/printing)-ийн дагуу дахин хэвлэ.
- Зураг хэт хазайсан/бүдэг бол [Сканнердах зөвлөмж](/user/scanning)-ийг дага.

### Олон хуудас "шалгах шаардлагатай" гэж гарч байна

- Бөмбөлгүүд хагас будагдсан буюу баллуурдсан байж магадгүй. [Гараар шалгах](/user/review)
  дэлгэцэд нягтлан зас.
- Хэвлэлтийн масштаб 100% биш бол бөмбөлгийн байрлал зөрж болзошгүй.

### Хувилбар буруу таних

- Хуудасны **Хувилбар** бүлэг зөв бөглөгдсөн эсэхийг шалга. Шаардвал гараар шалгах дэлгэцээс
  хувилбарыг дахин сонго.

### Шифрлэсэн `.shalgalt` файл нээгдэхгүй

- **Нууц үг** зөв эсэхийг шалга. Файлын ерөнхий мэдээллийн **hint** (сануулга) -ыг харж болно.

### Дүн Excel рүү гарахгүй

- Бичих эрхтэй фолдер сонгосон эсэхээ шалга.

### Интернэт хэрэгтэй юу?

- **Үгүй.** Программ бүрэн офлайн ажиллана. [Нууцлал](/user/privacy)-ыг үзнэ үү.
