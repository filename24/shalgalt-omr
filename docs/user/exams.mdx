# Шалгалт удирдах

**Шалгалт** нь нэг загвар дээр суурилсан, өөрийн **хариултын түлхүүр**-тэй нэгж юм. Нэг
шалгалт олон **хувилбар**-тай байж болно (жишээ нь A, B хувилбар).

## Шалгалт үүсгэх

1. **Шалгалт** цэс рүү орно.
2. **Шинэ шалгалт** дарж нэр өгч, ашиглах **загвар**-аа сонгоно.
3. Үүссэн шалгалт жагсаалтад нэр, загвар, хувилбарын тоо, огнооны хамт харагдана.

## Хариултын түлхүүр (хувилбар) оруулах

Шалгалтаа нээгээд хувилбар нэмнэ. Зөв хариултыг оруулах **хоёр арга**:

1. **Гараар** — асуулт бүрийн зөв хариултыг сонгоно.
2. **Сканнердан уншуулах** — багшийн бөглөсөн нэг хуудсыг сканнердаж, програмаар уншуулаад,
   зэрэгцүүлэн шалгаж хадгална.

> 📷 *Дэлгэцийн зураг: Шалгалтын дэлгэрэнгүй — хувилбарын жагсаалт ба хариултын түлхүүр засах.*

## Тэмдэглэл

- Хариултын түлхүүр нь тухайн шалгалтын **асуултуудын багц** юм. Хэрэв зарим асуултад түлхүүр
  оруулаагүй бол (хэсэгчилсэн шалгалт) тэдгээр асуултыг дүгнэхдээ алгасна.
