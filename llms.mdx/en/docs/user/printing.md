# Хэвлэх зөвлөмж (https://filename24.github.io/shalgalt-omr/en/docs/user/printing)



Хариултын хуудсыг зөв хэвлэх нь автомат таних чанарт шууд нөлөөлнө.

<Callout type="warn" title="Масштаб 100%">
  "Fit to page" / "хуудсанд багтаах" сонголтыг **унтраа**. Багасгаж/томруулж хэвлэвэл
  бөмбөлгийн байрлал зөрж таних алдаа гарна.
</Callout>

* **Тод хар бэх, хангалттай тонер.** Бүдэг хэвлэлт булангийн ArUco тэмдгийг таниулахад хүндрэл
  учруулна.
* **Цагаан, гялбаагүй (matte) A4 цаас.** Өнгөт эсвэл гялгар цаас сканнердахад туссан гэрэл
  үүсгэж болзошгүй.
* **Хуудсыг бүтнээр нь хэвлэ** — 4 булангийн тэмдэг бүгд гарсан эсэхийг шалга.

<Callout title="Зөвлөмж">
  Олон хувь хэвлэхдээ нэгийг туршиж сканнердан үзээд дараа нь олноор хэвлэвэл найдвартай.
</Callout>
