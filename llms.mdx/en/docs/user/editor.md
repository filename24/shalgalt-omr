# Загвар засварлагч [#загвар-засварлагч]

Засварлагч нь хариултын хуудасны **загвар** (template) зохиох газар юм. Загвар нь дараах
хэсгүүдээс бүрдэнэ:

* **Булангийн тэмдэг (ArUco)** — хуудасны 4 буланд байрлах бөгөөд програм хуудсыг танихад
  ашиглана. Анхдагчаар бэлэн ирнэ.
* **Бөмбөлгийн бүлэг** — асуулт бүрийн сонголтын бөмбөлгүүд (жишээ нь A, B, C, D).
* **Сурагчийн дугаар** ба **Хувилбар**-ын бүлэг (заавал биш).

## Үндсэн алхмууд [#үндсэн-алхмууд]

1. **Хяналтын самбар → Шинэ загвар** дарж засварлагчийг нээнэ. Эсвэл одоо байгаа загвараа
   нээнэ.
2. Шаардлагатай бол **дэвсгэр зураг** (хэвлэсэн хуудасны зураг/PDF) импортлон, түүн дээрээ
   бөмбөлгүүдээ тааруулна.
3. **Бөмбөлгийн бүлэг нэмэх** товчоор асуултуудаа нэмж, тоо, зай, оноог тохируулна.
4. **Хадгалах** дарна. **Буцаах / Дахих** (undo/redo) товчлуурууд дэмжигдэнэ.
5. **PDF болгон гаргах** товчоор хэвлэхэд бэлэн хуудас үүсгэнэ.

> 📷 &#x2A;Дэлгэцийн зураг: Засварлагчийн хэрэгслийн мөр (шинэ/нээх/хадгалах/буцаах/гаргах).*

## Зөвлөмж [#зөвлөмж]

* Бүх координат **0–1 хооронд хувь**-аар хадгалагдах тул нэг загвар янз бүрийн хэмжээ,
  чанартай хэвлэлд тохирно.
* Хэвлэхдээ масштабыг 100% байлгана — [Хэвлэх зөвлөмж](/user/printing).
