# Нууцлалын мэдэгдэл (https://filename24.github.io/shalgalt-omr/en/docs/user/privacy)



shalgalt-omr нь **нууцлалыг эн тэргүүнд** тавьсан, бүрэн офлайн программ юм.

<Callout type="success" title="Бүрэн офлайн">
  Дүгнэх, хадгалах, гаргах бүх үйлдэл таны компьютер дээр явагдах тул интернэт шаарддаггүй.
</Callout>

* **Ямар ч мэдээлэл гадагш илгээдэггүй.** Телеметр, алдааны тайлан, аналитик **байхгүй**.
* **Сурагчдын мэдээлэл зөвхөн локал** өгөгдлийн санд хадгалагдана.
* `.shalgalt` файлыг хуваалцахдаа **нууц үгээр шифрлэх** боломжтой. Шифрлэсэн үед ч төслийн
  ерөнхий мэдээллийн (manifest) хэсэгт **хувийн мэдээлэл агуулагдахгүй**.
* Зөвхөн &#x2A;*локал бүртгэл (log)** хөтлөгдөж, тодорхой хэмжээнд эргэлдэж шинэчлэгдэнэ.

<Callout type="info" title="Анхаар">
  Автомат шинэчлэлт (auto-update) нь **анхдагчаар унтраалттай** тул офлайн орчинд ажилладаг
  сургуулиуд ямар нэг сүлжээний хүсэлт хүлээж авахгүй. Та тохиргооноос гараар асааж болно.
</Callout>
