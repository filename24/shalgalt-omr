# Introduction (https://filename24.github.io/shalgalt-omr/en/docs/user)



**shalgalt-omr** reads and grades OMR (fill-the-bubble) answer sheets automatically,
**fully offline**, on your own computer. As a teacher you can:

<Cards>
  <Card href="/user/editor" title="Design a template">
    Draw the answer-sheet layout in a visual editor.
  </Card>

  <Card href="/user/editor" title="Generate a printable PDF">
    Save that template as a print-ready PDF.
  </Card>

  <Card href="/user/grading" title="Grade">
    Grade scanned or phone-photographed sheets automatically.
  </Card>

  <Card href="/user/review" title="Review">
    Review low-confidence sheets by hand.
  </Card>

  <Card href="/user/export" title="Export">
    Export results to Excel, or share a whole project as a `.shalgalt` file.
  </Card>
</Cards>

<Callout type="info" title="Mongolian-only interface">
  The interface of the application itself is in **Mongolian only**. This English manual is a
  translation of the Mongolian user guide; some pages may fall back to Mongolian until their
  translation is added.
</Callout>

## Privacy [#privacy]

<Callout type="success" title="Fully offline">

  computer. See the [Privacy statement](/user/privacy).
