# Storyboard: Эхний шалгалтыг дүгнэх (https://filename24.github.io/shalgalt-omr/mn/docs/user/walkthroughs/first-grade)



Эхний шалгалтаа дүгнэх ≈5 минутын танилцуулга видеоны дүр зураг. Алхам бүрт дэлгэцийн
үйлдэл, нэрлэгчийн дуу, тэмдэглэл багтсан.

<Steps>
  <Step>
    ### Хяналтын самбар нээгдэнэ [#хяналтын-самбар-нээгдэнэ]

    Дуу (нэрлэгч): "shalgalt-omr-оор эхний шалгалтаа хэрхэн дүгнэхийг үзье."

    Тэмдэглэл: Лого, нүүр хуудас.
  </Step>

  <Step>
    ### "Шинэ загвар" дарж засварлагч руу орно [#шинэ-загвар-дарж-засварлагч-руу-орно]

    Дуу (нэрлэгч): "Эхлээд хариултын хуудасны загвараа зохионо."

    Тэмдэглэл: [Загвар засварлагч](/user/editor).
  </Step>

  <Step>
    ### Бөмбөлгийн бүлэг нэмж хадгална [#бөмбөлгийн-бүлэг-нэмж-хадгална]

    Дуу (нэрлэгч): "Асуултуудаа нэмээд хадгалъя."

    Тэмдэглэл: undo/redo харуул.
  </Step>

  <Step>
    ### "PDF болгон гаргах" [#pdf-болгон-гаргах]

    Дуу (нэрлэгч): "Дараа нь хэвлэх хуудсыг гаргана."

    Тэмдэглэл: Масштаб 100% сануул.
  </Step>

  <Step>
    ### Шалгалт үүсгэж, хариултын түлхүүр оруулна [#шалгалт-үүсгэж-хариултын-түлхүүр-оруулна]

    Дуу (нэрлэгч): "Шалгалт үүсгэж зөв хариултаа оруулна."

    Тэмдэглэл: [Шалгалт](/user/exams).
  </Step>

  <Step>
    ### "Дүгнэх" — PDF сонгож, эхлүүлнэ [#дүгнэх--pdf-сонгож-эхлүүлнэ]

    Дуу (нэрлэгч): "Сканнердсан хуудаснуудаа сонгоод эхлүүлнэ."

    Тэмдэглэл: Дэвшилтийн мөр.
  </Step>

  <Step>
    ### Эргэлзээтэй хуудсыг гараар шалгана [#эргэлзээтэй-хуудсыг-гараар-шалгана]

    Дуу (нэрлэгч): "Эргэлзээтэй хуудсыг гар аргаар нягтална."

    Тэмдэглэл: [Гараар шалгах](/user/review).
  </Step>

  <Step>
    ### "Дүн" — Excel рүү гаргана [#дүн--excel-рүү-гаргана]

    Дуу (нэрлэгч): "Эцэст нь дүнг Excel-рүү гаргана."

    Тэмдэглэл: [Excel рүү гаргах](/user/export).
  </Step>
</Steps>
