# Storyboard: Шифрлэсэн төсөл хуваалцах (https://filename24.github.io/shalgalt-omr/mn/docs/user/walkthroughs/encrypted-project)



Шифрлэсэн төслөө аюулгүй хуваалцах ≈3 минутын танилцуулга видеоны дүр зураг. Алхам бүрт
дэлгэцийн үйлдэл, нэрлэгчийн дуу, тэмдэглэл багтсан.

<Steps>
  <Step>
    ### Дүгнэсэн шалгалт нээлттэй байна [#дүгнэсэн-шалгалт-нээлттэй-байна]

    Дуу (нэрлэгч): "Бэлэн болсон төслөө аюулгүй хуваалцъя."

    Тэмдэглэл: [Төслийн файл](/user/project-files).
  </Step>

  <Step>
    ### "Гаргах" → нууц үг тавих сонголт [#гаргах--нууц-үг-тавих-сонголт]

    Дуу (нэрлэгч): "Гаргахдаа нууц үг тавьж шифрлэнэ."

    Тэмдэглэл: passphrase оруулах.
  </Step>

  <Step>
    ### `.shalgalt` файл үүснэ [#shalgalt-файл-үүснэ]

    Дуу (нэрлэгч): "Бүх агуулга шифрлэгдэнэ — зөвхөн ерөнхий мэдээлэл задгай."

    Тэмдэглэл: manifest задгай.
  </Step>

  <Step>
    ### Файлыг хамтран ажиллагсадад илгээнэ [#файлыг-хамтран-ажиллагсадад-илгээнэ]

    Дуу (нэрлэгч): "Файлаа имэйл/USB-ээр дамжуулна."

    Тэмдэглэл: офлайн ч болно.
  </Step>

  <Step>
    ### Хүлээн авагч давхар товшино [#хүлээн-авагч-давхар-товшино]

    Дуу (нэрлэгч): "Нээхэд нууц үг асууна."

    Тэмдэглэл: hint харагдана.
  </Step>

  <Step>
    ### Нууц үг оруулж сэргээнэ [#нууц-үг-оруулж-сэргээнэ]

    Дуу (нэрлэгч): "Зөв нууц үгээр төсөл сэргэнэ."

    Тэмдэглэл: [Жишээ: `shalgalt-2026`](/user/samples).
  </Step>
</Steps>

<Callout type="info" title="Зөвлөмж">
  Жишээ болгон `sample-encrypted.shalgalt` (нууц үг: `shalgalt-2026`)-ийг ашиглаж болно.
</Callout>
