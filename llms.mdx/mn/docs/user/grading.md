# Дүгнэх (https://filename24.github.io/shalgalt-omr/mn/docs/user/grading)



Дүгнэх дэлгэц нь сканнердсан буюу гар утсаар авсан хуудаснуудыг **багцаар** автоматаар уншиж
оноо тавина.

## Алхмууд [#алхмууд]

<Steps>
  <Step>
    ### Дүгнэх цэс рүү орох [#дүгнэх-цэс-рүү-орох]

    **Дүгнэх** цэс рүү орно.
  </Step>

  <Step>
    ### Файлуудаа сонгох [#файлуудаа-сонгох]

    Сканнердсан &#x2A;*PDF файл(ууд)**-аа сонгоно (олон файл/олон хуудас дэмжигдэнэ).
  </Step>

  <Step>
    ### Шалгалт ба хувилбар сонгох [#шалгалт-ба-хувилбар-сонгох]

    Дүгнэх **шалгалт** ба **хувилбар**-аа сонгоно. Олон хувилбартай үед **автомат таних**-ийг
    идэвхжүүлж болно — хуудас бүрийн хувилбарын бүлгээс уншина.
  </Step>

  <Step>
    ### Эхлүүлэх [#эхлүүлэх]

    **Эхлүүлэх** дарна. Явц **дэвшилтийн мөр**-өөр харагдана (хуудас засварлах, тэмдэг таних,
    бөмбөлөг хэмжих гэх мэт үе шатууд). Энэ хооронд програм **царцахгүй**.
  </Step>

  <Step>
    ### Дүн харах [#дүн-харах]

    Дуусахад нийт хуудас, дундаж оноо, **шалгах шаардлагатай** хуудасны тоо харагдана.
  </Step>
</Steps>

<Callout type="info" title="Дэлгэцийн зураг">
  Дүгнэх дэлгэц — файл сонголт, хувилбар, дэвшилтийн мөр.
</Callout>

## Итгэлийн оноо ба шалгах шаардлага [#итгэлийн-оноо-ба-шалгах-шаардлага]

<Callout type="info" title="Анхаар">
  Программ бөмбөлөг бүрийн дүүргэлтийг хэмжиж **итгэлийн оноо** тооцно. Хэрэв аль нэг бөмбөлгийн
  итгэл эргэлзээтэй мужид (хагас будсан) орвол тухайн хуудсыг **шалгах шаардлагатай** гэж
  тэмдэглэнэ. Эдгээрийг [Гараар шалгах](/user/review) дэлгэцэд засна.
</Callout>
