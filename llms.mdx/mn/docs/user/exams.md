# Шалгалт удирдах (https://filename24.github.io/shalgalt-omr/mn/docs/user/exams)



**Шалгалт** нь нэг загвар дээр суурилсан, өөрийн **хариултын түлхүүр**-тэй нэгж юм. Нэг
шалгалт олон **хувилбар**-тай байж болно (жишээ нь A, B хувилбар).

## Шалгалт үүсгэх [#шалгалт-үүсгэх]

<Steps>
  <Step>
    ### Шалгалт цэс рүү орох [#шалгалт-цэс-рүү-орох]

    **Шалгалт** цэс рүү орно.
  </Step>

  <Step>
    ### Шинэ шалгалт үүсгэх [#шинэ-шалгалт-үүсгэх]

    **Шинэ шалгалт** дарж нэр өгч, ашиглах **загвар**-аа сонгоно.
  </Step>

  <Step>
    ### Жагсаалтаас харах [#жагсаалтаас-харах]

    Үүссэн шалгалт жагсаалтад нэр, загвар, хувилбарын тоо, огнооны хамт харагдана.
  </Step>
</Steps>

## Хариултын түлхүүр (хувилбар) оруулах [#хариултын-түлхүүр-хувилбар-оруулах]

Шалгалтаа нээгээд хувилбар нэмнэ. Зөв хариултыг оруулах **хоёр арга**:

<Cards>
  <Card title="Гараар">
    Асуулт бүрийн зөв хариултыг сонгоно.
  </Card>

  <Card title="Сканнердан уншуулах">
    Багшийн бөглөсөн нэг хуудсыг сканнердаж, програмаар уншуулаад, зэрэгцүүлэн шалгаж
    хадгална.
  </Card>
</Cards>

<Callout type="info" title="Дэлгэцийн зураг">
  Шалгалтын дэлгэрэнгүй — хувилбарын жагсаалт ба хариултын түлхүүр засах.
</Callout>

## Тэмдэглэл [#тэмдэглэл]

<Callout type="info" title="Анхаар">
  Хариултын түлхүүр нь тухайн шалгалтын **асуултуудын багц** юм. Хэрэв зарим асуултад түлхүүр
  оруулаагүй бол (хэсэгчилсэн шалгалт) тэдгээр асуултыг дүгнэхдээ алгасна.
</Callout>
