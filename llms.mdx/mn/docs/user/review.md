# Гараар шалгах (https://filename24.github.io/shalgalt-omr/mn/docs/user/review)



Дүгнэлтийн дараа **шалгах шаардлагатай** гэж тэмдэглэгдсэн хуудсуудыг энд гар аргаар
нягталж засна.

## Алхмууд [#алхмууд]

<Steps>
  <Step>
    ### Гараар шалгах руу орох [#гараар-шалгах-руу-орох]

    Дүгнэлт дуусахад гарах холбоосоор, эсвэл тухайн ажлын (job) дэлгэцээс **Гараар шалгах**
    руу орно.
  </Step>

  <Step>
    ### Хуудаснуудаа сонгох [#хуудаснуудаа-сонгох]

    Зүүн талд хуудаснуудын &#x2A;*жижиг зураг (thumbnail)** жагсаалт харагдана.
  </Step>

  <Step>
    ### Бөмбөлгийн төлвийг засах [#бөмбөлгийн-төлвийг-засах]

    Голд сонгосон хуудасны зураг дээр **бөмбөлгийн давхарга** харагдана. Бөмбөлгийг дарж
    төлвийг солино: **будсан → хоосон → эргэлзээтэй**.
  </Step>

  <Step>
    ### Хувилбарыг засах [#хувилбарыг-засах]

    Шаардлагатай бол хуудасны **хувилбар**-ыг дахин сонгож зөв болгоно.
  </Step>

  <Step>
    ### Дахин дүгнэж хадгалах [#дахин-дүгнэж-хадгалах]

    Засвар хийсний дараа тухайн хуудас **дахин дүгнэгдэнэ**. Эцэст нь **Хадгалах**.
  </Step>
</Steps>

<Callout type="info" title="Дэлгэцийн зураг">
  Гараар шалгах — thumbnail жагсаалт, бөмбөлгийн давхаргатай зураг.
</Callout>

## Зөвлөмж [#зөвлөмж]

<Callout type="info" title="Зөвлөмж">
  Зөвхөн **эргэлзээтэй** бөмбөлгүүдэд анхаарлаа хандуулна — програм аль нь эргэлзээтэйг
  ялган тэмдэглэдэг.
</Callout>
