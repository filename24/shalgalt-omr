# Гараар шалгах [#гараар-шалгах]

Дүгнэлтийн дараа **шалгах шаардлагатай** гэж тэмдэглэгдсэн хуудсуудыг энд гар аргаар
нягталж засна.

## Алхмууд [#алхмууд]

1. Дүгнэлт дуусахад гарах холбоосоор, эсвэл тухайн ажлын (job) дэлгэцээс **Гараар шалгах**
   руу орно.
2. Зүүн талд хуудаснуудын &#x2A;*жижиг зураг (thumbnail)** жагсаалт харагдана.
3. Голд сонгосон хуудасны зураг дээр **бөмбөлгийн давхарга** харагдана. Бөмбөлгийг дарж
   төлвийг солино: **будсан → хоосон → эргэлзээтэй**.
4. Шаардлагатай бол хуудасны **хувилбар**-ыг дахин сонгож зөв болгоно.
5. Засвар хийсний дараа тухайн хуудас **дахин дүгнэгдэнэ**. Эцэст нь **Хадгалах**.

> 📷 &#x2A;Дэлгэцийн зураг: Гараар шалгах — thumbnail жагсаалт, бөмбөлгийн давхаргатай зураг.*

## Зөвлөмж [#зөвлөмж]

* Зөвхөн **эргэлзээтэй** бөмбөлгүүдэд анхаарлаа хандуулна — програм аль нь эргэлзээтэйг
  ялган тэмдэглэдэг.
